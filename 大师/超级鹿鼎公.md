# 超级鹿鼎公的投资道与术：核心是防御、估值与复利

我把雪球大 V 超级鹿鼎公 的投资体系概括为一句话：

其公开投资理念常被归纳为“价值选股、趋势选时、估值定仓、波动降本”。

## 价值选股、趋势选时、估值定仓、波动降本

用价值投资决定买什么，用估值决定买多少，用趋势辅助判断何时买卖，再用分红和波动管理积累复利。

他的特点不是单纯买入高股息股票后长期躺平，而是把传统价值投资、周期判断、仓位管理和波段交易结合起来。

先说明一点：网上大量总结来自其他投资者对他的持仓和文章的归纳，并非每一条都能确认是他本人制定的硬性规则。因此，下面会区分核心理念与外界总结出的操作方法。

## 一、投资之道：决定长期靠什么赚钱

\1. 防御优先：不输比短期赢得多更重要

他强调的不是追逐最热门的行业，而是尽量买入经营相对稳定、现金流充沛、能够持续分红的企业。其代表性持仓思路集中于水电、煤炭、公用事业等传统行业。

逻辑是：股票本身已经有风险，不必再为高成长故事支付昂贵价格。少犯大错、避免永久性本金损失，才能让复利持续运转。

\2. 买有壁垒的资产：优先考虑垄断性与稳定现金流

他偏好资源禀赋、规模优势、牌照或基础设施壁垒较强的企业，例如水电、煤炭和部分大型公用事业公司。

这类企业的吸引力在于商业模式相对容易分析，竞争格局不容易在短时间内彻底改变，且盈利可以通过分红转化为股东的实际回报。

但“垄断”并不等于没有风险：煤炭仍受周期影响，公用事业受政策和资本开支影响，资源企业也可能遭遇价格下跌。

\3. 低估才是买入理由，而不是“公司不错”

他并不满足于找到好公司，还强调价格必须足够有吸引力。常见筛选维度包括低 PE、低 PB、较低负债、较高股息率，以及能够支撑分红的现金流。

好公司不等于好股票，好股息也不等于好投资。 如果盈利正处于周期顶部，当前低 PE 可能是陷阱；如果分红依赖举债或消耗资产，高股息也可能不可持续。

\4. 把分红看成现金回报，而不只盯着股价

买入后，收益来源不只是股价上涨，还包括企业分红，以及低估时买入、估值回归后的资本利得。

分红的意义是把一部分企业经营成果直接兑现给股东；如果股价长期横盘，真实、可持续的分红仍然能够贡献收益。不过，除息后股价会相应调整，分红不是额外凭空创造的财富。

## 二、投资之术：如何把理念落实到交易

他的实操方法，可以拆成四个环节。

## 01

价值选股：先缩小能力圈

重点研究商业模式、行业壁垒、盈利质量、资产负债表、现金流和分红能力。先排除财务风险高、负债沉重、估值过高或盈利质量差的公司，再从剩余标的中寻找价格有吸引力的企业。

这一步决定的是：什么资产值得长期跟踪和持有。

## 02

趋势选时：不要求精准抄底

在他的部分操作思路中，估值、市场情绪、宏观环境和价格走势会一起考虑。理想状态是公司便宜、基本面没有恶化，市场又极度悲观；如果价格已经明显走强、经营趋势得到确认，也可能考虑顺势调整仓位。

他公开谈过自己更偏向左侧买入、愿意承受一定浮亏，而不是等趋势形成后追高。

这意味着趋势判断是辅助工具，而不是准确预测底部的能力。

## 03

估值定仓：越便宜越值得配置，但必须留有余地

不是每只股票都买同样多，也不是看到下跌就无限补仓。估值越有吸引力、基本面越可靠，才越有理由提高配置；估值接近合理甚至偏贵时，则降低新增投入或逐步兑现。

真正的关键是先定义合理价值与最坏情景，再确定仓位。否则，“越跌越买”很容易从逆向投资变成拒绝承认判断错误。

## 04

波动降本：利用波动，但不轻易动核心逻辑

在核心持仓不变或大体保留的前提下，用较小的交易仓位做高抛低吸，试图改善整体持仓成本。

这种做法需要对企业价值有判断，并且需要严格控制交易仓位。如果反复卖出后价格继续上涨，可能买不回来；如果股票基本面恶化，所谓“做 T 降成本”也无法挽救一笔错误投资。

降低账面成本不等于提高真实收益。 评价效果必须看扣除交易费用、税费和踏空机会后的总回报。

## 三、他的估值方法：把股票当成能够持续产生现金的资产

这部分尤其值得理解。

他比较看重股息率，并尝试用存款利率作为参照：买股票不只是为了将来有人出更高的价格接盘，而是希望企业持续创造现金，自己能够不断收到分红。

不过，不能把网上流传的某个股息率门槛，当成适用于所有公司的固定估值公式。

举个例子：

假设某公司每股每年可持续分红 1 元。

| 买入价格 | 股息率 | 投资含义                                 |
| -------- | ------ | ---------------------------------------- |
| 25 元    | 4%     | 回报吸引力一般，仍需看增长和风险         |
| 20 元    | 5%     | 现金回报更有吸引力                       |
| 16.67 元 | 6%     | 若分红可持续，安全边际更厚               |
| 12.50 元 | 8%     | 可能非常便宜，也可能市场正在预期盈利恶化 |

这里最重要的不是简单地追求最高股息率，而是回答三个问题：

1. 分红能持续多久？ 未来几年利润和自由现金流能否覆盖分红？
2. 盈利是否处于周期高点？ 煤炭等周期行业尤其需要用正常化利润估值，而不是直接用当期 PE。
3. 股价为何便宜？ 是市场情绪导致的错杀，还是竞争力、盈利能力或分红能力发生了永久性变化？

超级鹿鼎公这类策略的优势，是把投资决策尽量锚定在可获得的现金回报与低估值上；难点是判断当前的高股息究竟代表低估，还是代表市场预期未来分红将下降。

## 四、他的体系如何形成复利？

可以把收益来源分为三部分：

第一部分：分红收益

企业持续分红，提供可兑现的现金回报；如果不需要消费，可以把分红继续投入有吸引力的资产。

第二部分：估值修复

在市场悲观时以低于合理价值的价格买入，未来当估值回归时，获得资本利得。

第三部分：交易优化

通过仓位调整、适度波段交易和跨标的比较，争取增加收益或降低风险。但这部分不是必然盈利，也不应成为投资逻辑的核心。

三部分里，我认为最值得普通投资者学习的是前两部分：以合理价格买入有持续现金创造能力的资产，并耐心等待现金回报和估值修复。 波段交易需要额外的能力，未必适合每个人。

## 五、不能忽视的风险与局限

他的投资方法有可借鉴之处，但不能把历史收益简单理解成未来收益的保证。

- 高股息陷阱： 股息率可能因股价下跌而上升，但分红也可能随利润下降而减少。
- 周期股误判： 周期高点的低 PE，往往比表面看起来更贵。需要关注中周期盈利、成本曲线和资本开支。
- 风格集中： 即使买了多家公司，如果它们都依赖低利率、高股息或某一类资源价格，风险可能高度相关。
- 做 T 的机会成本： 交易越频繁，越容易错过上涨，也增加费用和执行错误。
- 公开实盘的可复制性： 公开账户记录有参考价值，但其他投资者的资金规模、买入价格、交易纪律和风险承受能力并不相同。近期也有雪球文章分析过，跟随其公开持仓未必能复制相同收益。

此外，公开资料对他的收益率、回撤和操作规则存在不同口径。更稳妥的做法是把公开实盘当成研究样本，而不是把网络文章中的收益数字当成独立审计的业绩保证。

## 六、结合你的投资风格，哪些值得借鉴？

你本身就偏向价值投资，重视本金安全、现金流和安全边际，也不愿意仅因为股息率达到 4%–4.5% 就急于买入。因此，我建议你重点借鉴他的估值纪律与风险控制，而不是照搬全部交易技巧。

| 他的做法   | 对你的借鉴价值 | 我的建议                                                     |
| ---------- | -------------- | ------------------------------------------------------------ |
| 价值选股   | 很高           | 研究护城河、正常化利润、自由现金流与分红能力                 |
| 趋势选时   | 中等           | 可以观察库存、价格趋势和经营数据，但不要依赖技术信号替代估值 |
| 估值定仓   | 很高           | 预设买入区间与仓位上限，避免一次性押注                       |
| 波动降本   | 有条件         | 如果没有经过复盘验证，不必为了降低持仓成本频繁做 T           |
| 高股息策略 | 较高           | 区分稳定现金流型红利资产与周期高峰型高股息资产               |

特别是你最近研究的云铝股份和神火股份：这类周期股可以借鉴他的逆向投资思路，但不能只看当期 PE 或股息率。

你需要先估算不同铝价、氧化铝成本和能源成本情景下的正常化利润，再看当前价格对应的估值与可持续股息率。只有当悲观情景下仍有安全边际，才适合考虑加大仓位。

## 我的最终总结

超级鹿鼎公最值得学习的，不是某只股票，也不是某个做 T 技巧，而是他试图建立一套完整的投资纪律：

- 道： 防御优先，寻找有壁垒、现金流好、价格足够低的资产。
- 选股之术： 通过财务质量、估值、分红与行业地位筛选标的。
- 择时之术： 尽量在低估和悲观时布局，不执着于精准抄底。
- 仓位之术： 根据估值和风险调整投入，而不是一跌就无限补仓。
- 交易之术： 用分红和估值修复作为主要收益来源，把波段交易视为可选的辅助工具。

如果只学一条，我建议你学“估值决定仓位”，而不是学“高股息”或“做 T”。 同一家公司，买得便宜与买得昂贵，长期结果可能完全不同；而正确的仓位能让你在判断出错时仍然有继续投资的余地。
